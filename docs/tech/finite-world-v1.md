# 第一阶段：有限世界与单细胞初始定义

## 我们现在只验证一件事

> 在一个有限、可重复、参数可调的二维世界中，一个初始没有趋食和避险倾向的单细胞，能否仅通过繁殖时的遗传变异与环境筛选，使后代群体逐渐提高可存活后代数量？

这句话包含三个重要边界：

1. 细胞没有被写入“寻找食物”或“躲避危险”的目标；
2. 环境只执行规则，不教细胞正确答案；
3. 我们观察的优化量是**可存活后代数量**，不是给个体公开的奖励分数。

数学上，可把某一基因型 `g` 在环境 `E` 和观察窗口 `T` 下的适应度写成：

```text
F(g | E, T) = 观察窗口结束时，由 g 的谱系产生且仍存活的后代数
```

后续还可以增加寿命、资源效率与谱系稳定性，但第一阶段不混合多个目标。

## 为什么世界先用 128 × 128

此前设计的超大稀疏世界仍作为远期架构方向，但不适合第一个实验。第一版采用：

```text
128 × 128 = 16,384 个格点
```

原因：

- 足够容纳局部资源斑块和多个谱系扩张；
- 可以稠密表示，容易检查每个格点和事件；
- 单次仿真可以运行数千到数万 tick；
- 后续扩大到 256、512 或稀疏世界时，核心规则不变。

边界第一版采用**环面**：从右侧越界会回到左侧，避免人为墙边成为特殊生存区。

## 世界中有哪些东西

第一版只有三类格点：

| 格点 | 作用 |
|---|---|
| 空白 | 可以移动或繁殖 |
| 食物 | 被细胞摄取后转化为能量并消失 |
| 危险 | 进入后造成能量损失，不一定立即死亡 |

外部可调参数：

| 参数 | 初始值 | 含义 |
|---|---:|---|
| `width`, `height` | 128, 128 | 世界尺寸 |
| `initial_resource_density` | 0.02 | 初始有食物格比例 |
| `resource_regeneration_rate` | 0.0001 | 每格每 tick 再生资源概率 |
| `initial_organisms` | 1 | 初始细胞数 |
| `max_ticks` | 10,000 | 首个实验时长 |
| `seed` | 1 | 世界与事件随机种子 |
| `mutation_probability` | 0.10 | 后代每个可遗传属性发生变异的概率 |
| `mutation_sigma` | 0.15 | 连续属性的变异尺度 |
| `population_limit` | 10,000 | 防止第一版种群失控 |

## 初始单细胞拥有什么

### 身体状态：不可直接遗传

| 属性 | 初始值 | 说明 |
|---|---:|---|
| 位置 | 世界中心附近 | 出生位置，不写入基因 |
| 能量 | 20 | 归零死亡 |
| 年龄 | 0 | 每 tick +1 |
| 最大年龄 | 500 tick | 第一版固定世界公理 |
| 基础代谢 | 1/tick | 活着就必须付出的成本 |
| 移动成本 | 1/次 | 动不动都不免费 |
| 感知半径 | 1 | 只见 3×3 局部区域 |
| 食物能量 | +12 | 世界规则，不是个体知识 |
| 危险伤害 | -10 | 世界规则 |

### 可遗传基因：创始细胞的初始值

| 基因 | 初始值 | 说明 |
|---|---:|---|
| `food_attraction` | 0.0 | 对食物方向没有偏好 |
| `hazard_avoidance` | 0.0 | 对危险方向没有偏好 |
| `horizontal_bias` | 0.0 | 不偏左/右 |
| `vertical_bias` | 0.0 | 不偏上/下 |
| `exploration` | 1.0 | 初始完全依赖随机探索 |
| `reproduction_threshold_delta` | 0.0 | 对繁殖阈值的遗传修正 |
| `basal_cost_delta` | 0.0 | 对代谢成本的遗传修正 |

关键设计：创始细胞没有“食物是好东西”这一语义。它只能看到局部格点信号，并按当前参数把不同方向打分；初始所有定向权重为零，所以行为主要来自探索噪声。某些后代因变异产生正的食物趋向或危险回避，如果这些倾向提高繁殖成功率，相关基因才可能扩散。

## 繁殖规则

第一版采用无性繁殖：

1. 个体能量达到繁殖阈值 30；
2. 扣除繁殖能量 15；
3. 在相邻空格产生一个后代；
4. 后代获得创始能量 20 或繁殖配置指定能量；
5. 复制亲代 Genome；
6. 每个可遗传属性独立按 10% 概率发生高斯扰动；
7. 记录 parent、child、generation、mutation delta。

繁殖失败（周围无空位）时不扣能量，避免执行顺序制造隐性惩罚。

## 每个 tick 的最小顺序

```text
1. 按固定 ID 顺序读取每个活细胞
2. 生成 3×3 局部观察
3. 基因参数 + 探索噪声 → 选择动作
4. 解决移动冲突
5. 扣除代谢与移动成本
6. 结算食物和危险
7. 满足阈值时繁殖并变异
8. 年龄/能量导致死亡
9. 按配置再生资源
10. 记录种群、出生、死亡、基因均值和谱系
```

第一版采用固定 ID 顺序，确保可重放。以后若改并行，需要明确冲突公平性。

## 第一组实验

我们不会一开始看“有没有智能”，而是跑三个对照世界：

### A. 无变异

```text
mutation_probability = 0
```

预期：创始细胞保持随机探索，群体不会系统性获得趋食能力。

### B. 有变异、资源稳定

```text
mutation_probability = 0.10
resource_regeneration_rate = 0.0001
```

观察：食物趋向基因均值是否随代次上升，存活后代数是否超过 A。

### C. 有变异、危险存在

在 B 基础上增加危险格。观察危险回避基因是否上升，以及过度回避是否降低摄食。

## 第一阶段验收标准

底层框架完成不等于演化成功。框架验收只要求：

- 同配置、同 seed 的事件日志与最终状态相同；
- 能量账本正确；
- 食物不会重复摄取；
- 死亡个体不再行动和繁殖；
- 后代基因来自亲代，仅通过记录的 mutation delta 改变；
- 外部参数通过配置改变，无需修改代码；
- 无变异对照的基因分布不漂移；
- 所有谱系关系可追踪。

“趋食能力涌现”是下一步实验结论，需要至少 30 个 seed 和无变异对照，不能用一次动画判断。
