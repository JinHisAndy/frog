# 历史档案导览

`archive/` 保存作者历史叙事、版本 README、AI 问答、理论资料与二进制文档。它们有研究和教学价值，但**不是当前 API、运行方式或证据结论**。

- `archive/narratives/`：原始根 README 叙事；
- `archive/historical-stages/`：按历史阶段保留 README、LICENSE、DOC；
- `archive/author-records/`：作者与 AI 的原始问答；
- `archive/reference/`：理论资料、旧英文说明与 CAD 文件；
- `archive/versions/018/`：018 原型原路径的遗留说明与许可证。

根 `LICENSE` 是当前权威许可证。历史目录中随附的 LICENSE 文本保留为档案语义，未经版权审计不得自行删除或改写。

若需要原 Java 实现，使用 Git 历史，而不是将其重新放入当前 Python 工作树。
