# 实验与代码索引（历史兼容层）

`frog/experiments/stage00_kernel` 到 `stage07_two_pixel_reflex` 是第一轮重构留下的**最小能力基线**。它们仍可运行、测试和阅读，但不再被叙述为彼此独立的项目章节。

请按 [能力路线](../capability-journey.md) 理解它们：

| 旧模块 | 在新路线中的意义 | 不能说明什么 |
|---|---|---|
| Stage 00 | 可重复世界 | 生命或学习 |
| Stage 01 | 生存代价 | 自主性 |
| Stage 02 | 选择/突变接口 | 真实适应进化 |
| Stage 03/04 | 局部观察与动作 | 复杂决策 |
| Stage 05 | 压缩发育表达 | 功能神经结构 |
| Stage 06/07 | 反馈隐藏的反射接口 | 模式泛化 |
| Stage 08 | 原 018 random_search | 自然演化或意识 |

今后新增实验应优先放在 `frog.life` 的完整闭环之上，而不是继续增加孤立 Stage。
