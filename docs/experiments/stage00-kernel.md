# Stage 00：确定性网格仿真内核

## 假设

在相同网格参数、根 seed 和步数下，离散仿真必须产出字节一致的轨迹 JSON。该阶段不包含学习、奖励、神经网络或“智能”结论。

## 最小环境

- 网格：默认 5×5；
- 状态：`x`、`y`、`tick`；
- 动作：上、下、左、右、静止；
- 边界：坐标被夹紧，任何 step 恰好增加一个 tick；
- 随机性：仅来自显式传入的根 seed。

## 基线与指标

本阶段的基线是同 seed 的重复运行。指标为：

- 轨迹 JSON 是否字节一致；
- 状态数是否等于 `steps + 1`；
- 所有坐标是否位于边界内。

## 验收

1. 单元测试覆盖边界移动与 tick；
2. 相同 seed 的两条轨迹 JSON 完全一致；
3. 后续 Stage 01 只能在此内核上增加能量与食物，不能绕过 `step()`。

## 停止条件

若 UI、全局随机数或 wall-clock 时间影响轨迹，停止后续功能开发，先修复确定性。
