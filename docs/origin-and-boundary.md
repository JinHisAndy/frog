# 我们与原项目的关系

这个仓库不是 `drinkjava2/frog` 的逐行 Python 移植，也不把原代码结构当作本项目的架构遗产。

## 我们继承的，是问题意识

原项目长期追问：

- 智能能否从感知、行动、奖惩与环境中长出来？
- 大脑结构能否被遗传、变异与发育规则生成，而非完全手工设计？
- 条件反射能否把模式与未来后果连接起来？
- 生命样行为与意识现象之间可能有什么关系？

这些问题启发了 Frog 的研究论题。

## 我们重新设计的，是一切可执行部分

当前项目原创地定义了：

- 可运行的 Python-first 架构；
- 世界—身体—观察—控制—记忆—遗传—发育的模块边界；
- 训练/盲测信息隔离；
- 确定性、JSON 输出、pytest、CI、链接检查；
- 能力路线和每个命题的失败条件；
- `random_search` 的诚实定位；
- 未来完整生命闭环实验的工程接口。

少量 Python 模块保留了原 018 的抽象元素（四像素、痛/甜反馈、逃/咬动作、阈值连接和化学标签），仅用于研究其最小设想与揭示其局限。
