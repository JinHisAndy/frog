# Java → Python 迁移

本 fork 已删除 Java 源、Maven 描述符及 Java 启动脚本。当前唯一可运行入口是 Python：`pyproject.toml` 和 `frog/`。

迁移保留了 018 原型的核心语义：四像素、痛/甜训练、逃跑/咬合输出、阈值节点、前向连接、化学标签、受限可塑性、固定盲测和回放。

迁移没有逐行重写历史 Java，也没有把原项目的长期目标误写为已经实现的能力。历史 Java 如需审查，请使用 Git 历史中迁移前提交 `c53751b` 及其祖先；档案中保留原叙事与素材，但均不可执行。

旧 Maven/脚本残留已从当前工作树移除，因为其源代码已不存在，保留只会制造错误运行入口。
