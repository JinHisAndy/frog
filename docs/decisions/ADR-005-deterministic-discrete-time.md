# ADR-005：先采用确定性离散事件时间

## 状态

Accepted

## Context

人工生命实验需要长时间运行和后续并行扩展，但在早期必须能解释每一次出生、动作、学习、突变和死亡。

## Decision

第一版采用离散 tick 与固定事件顺序；所有随机流从世界 seed 和事件键派生。墙钟倍速仅控制展示速度，不改变逻辑结果。并行化后若无法保证逐位一致，必须明确降级为统计可复现。

## Consequences

**Positive**：单步调试、回放、状态哈希和因果追踪简单可靠。

**Negative**：单线程吞吐有限；连续动力学需离散近似；未来并行化需要解决冲突与随机流分区。

## Alternatives

- 立即多线程：吞吐高，但事件顺序和重放复杂。
- 连续时间物理：表达力更强，但不适合作为首个可审计内核。
