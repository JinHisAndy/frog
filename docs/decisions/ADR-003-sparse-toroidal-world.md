# ADR-003：采用 2^23 边长的稀疏环面世界

## 状态

Accepted

## Context

需要让一个像素大小的单细胞处于远大于自身的世界，同时不能为约 70 万亿逻辑格分配稠密内存。按地球直径约 12,742 km、人体尺度约 1.70 m，尺度比约 750 万。

## Decision

世界边长采用 `2^23 = 8,388,608` 格，拓扑为二维环面。空间按 `256 × 256` chunk 切分，仅实例化活跃或含状态的 chunk。

## Consequences

**Positive**：尺度差与“人—地球”同量级；二进制寻址简单；没有硬墙边界；内存与活跃区域相关。

**Negative**：环面不是球面；超远距离的真实地理关系被简化；chunk 休眠/恢复需要严格状态一致性。

## Alternatives

- 小型固定地图：实现简单，但无法研究扩张、隔离和宏观生态。
- 稠密大数组：不可行。
- 球面网格：物理隐喻更好，但第一版邻域、寻址和可视化复杂度过高。
