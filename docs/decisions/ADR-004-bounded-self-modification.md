# ADR-004：自我改造只允许发生在受约束生命表示中

## 状态

Accepted

## Context

项目需要个体修改自身结构和属性，但任意改写 Python、字节码或宿主文件会破坏可复现性、安全性和谱系审计。

## Decision

生命只能修改或继承以下受约束状态：基因参数、发育指令、细胞图、控制网络参数、生命周期记忆。所有表示必须有类型、预算、序列化和校验器。生命不得访问文件、网络、进程或任意代码执行。

## Consequences

**Positive**：变异可回放、可比较、可限制；宿主环境安全；可以精确追踪“哪次突变带来什么结构”。

**Negative**：表达空间由我们设计，可能错过未知的创新形式；扩大指令集需要新增 ADR 和对照实验。

## Alternatives

- 任意代码自修改：表达力强，但不可控、不可审计，拒绝。
- 只允许固定长度参数：安全简单，但不足以表达细胞数和拓扑变化。
