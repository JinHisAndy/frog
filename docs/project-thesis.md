# 项目论题：我们为什么做 Frog

## 一个可以被否定的问题

Frog 想回答的不是“能否写出看起来聪明的行为”，而是：

> 在资源有限、感知不完整、行动有后果的世界中，是否存在一条可重复的工程路径，让一个系统逐步获得维持自身、依据经验预测、并把有利组织跨代保留下来的能力？

这句话故意不把“意识”塞进验收标准。意识可以是项目远期的哲学问题，却不能成为程序通过/失败的判断器。可判断的是：某种结构是否提升生存，某种记忆是否在反馈缺失时提升预测，某种遗传编码是否让适应更容易出现。

## 从原项目提炼出的五个设想

我们只保留以下具有实验价值的设想：

1. **生命需要闭环**：感知、行动、后果不能脱节；
2. **环境是塑形者**：不只训练“答题正确”，还让错误影响继续存在的能力；
3. **经验可变**：奖惩应留下可调用的痕迹；
4. **结构可传递**：适应不仅发生在单次生命周期，也可能跨代积累；
5. **复杂结构可压缩生成**：生物并不为每个细胞手写说明书，发育规则可能比直接枚举连接更可扩展。

原项目关于“条件反射是智能基础”的直觉，转化为本项目可检验的命题：**当反馈被遮蔽后，感知模式能否独立决定更有利的动作？**

## 本项目不接受的捷径

- 用固定地图、出生点或 episode 编号泄漏答案；
- 训练期看到甜/苦、测试期仍偷看甜/苦；
- 从单次随机成功推导“演化出智能”；
- 用生物名词装饰没有对应机制的代码；
- 用漂亮 GIF 替代配置、seed、测试集和原始数据；
- 把历史作者的观点当作本项目已验证结论。

## 远期问题

如果未来系统能稳定地自我维持、形成可迁移的预测、建立自我相关的内部状态模型、在新的环境中继续学习，我们才会重新讨论“生命样组织”“主观性”或“意识表现”等问题。届时也只能报告支持度与反例，不能宣布哲学问题被代码终结。
