# 02：从零到双像素条件反射的实验路线图

## 总原则

作者的长期愿景是“让环境和进化长出智能”。我们不跳过基本证明链。每个阶段必须先在**无 UI、固定 seed、可批量运行**的情况下过关，才增加可视化和复杂度。

```mermaid
flowchart LR
  S00[00 确定性内核] --> S01[01 生命周期]
  S01 --> S02[02 遗传演化]
  S02 --> S03[03 感知动作]
  S03 --> S04[04 行为任务]
  S04 --> S05[05 发育基因型]
  S05 --> S06[06 单像素反射]
  S06 --> S07[07 双像素反射]
  S07 --> S08[08 复盘 018]
```

## 统一成功标准

除阶段 00 外，每阶段必须：

- 使用至少 30 独立 seed；
- 有 train/validation/test 或等价的预注册评估划分；
- 有至少一个 baseline；
- 写入 `config.json`、`metadata.json`、`metrics.json`、`telemetry.csv`；
- 报告失败，不挑选单次成功动画；
- 遵守 [03-experiment-contract.md](03-experiment-contract.md)。

## Stage 00：确定性仿真内核

**作者对应线索**：`history/001_first_version` 的环境循环；但本阶段不复刻 UI。

| 项目 | 内容 |
|---|---|
| 学习目标 | 认识离散时间仿真、seed、状态转换和测试 |
| 假设 H00 | 同一初始状态和根 seed 下，仿真轨迹应逐 tick 完全一致 |
| 最小环境 | 5×5 网格；一个实体；动作 `UP/DOWN/LEFT/RIGHT/IDLE`；10 tick |
| 模块 | `SeededRandom`、`SimulationClock`、不可变 `WorldState`、`Environment.step()` |
| 测试 | 边界移动、tick 增加、两个相同 seed 的轨迹逐项相等、不同 seed 可不同 |
| 可视化 | 输出 ASCII 网格或 CSV；暂不做 Swing |
| 验收 | 100 次重复同 seed 结果字节级一致；全部单测通过 |
| 停止条件 | 任何隐式随机数或 UI 线程改变逻辑，先修内核 |

## Stage 01：能量、死亡与最简单生命周期

**作者对应线索**：`history/001_first_version`、根目录 `result1.gif`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 区分环境规则与“智能策略” |
| 假设 H01 | 在能量递减和食物奖励下，吃到食物的固定策略拥有更高终局能量 |
| 最小环境 | 5×5 网格；固定食物；每 tick 能量 -1；吃到 +10；能量 ≤ 0 死亡 |
| 模块 | `AgentState`、`Food`、`EpisodeResult`、固定策略接口 |
| 对照 | `IdlePolicy`、`RandomPolicy`、`GreedyKnownFoodPolicy`（明确标为规则上限） |
| 测试 | 能量守恒、吃食物只结算一次、死亡停止、终止原因正确 |
| 可视化 | 能量—时间折线；网格轨迹 |
| 验收 | 贪心规则在锁定地图上优于随机；这只验证环境正确，不验证学习 |
| 常见误判 | 不要把“有食物时走过去”称作演化能力 |

## Stage 02：遗传、突变与代际选择

**作者对应线索**：`history/001_first_version` 的蛋/孵化，早期 `Egg` 代码。

| 项目 | 内容 |
|---|---|
| 学习目标 | 把“个体生命周期内学习”和“跨代遗传”分开 |
| 假设 H02 | 在固定环境中，选择 + 有界突变能提升种群平均适应度，且不会越界/失去多样性 |
| 最小环境 | 基因只编码 4 个动作偏好；每代 50 个个体；精英保留 + 锦标赛选择 + 高斯/离散突变 |
| 模块 | `Genome`、`Population`、`FitnessEvaluator`、`SelectionStrategy`、`MutationOperator` |
| 对照 | 纯随机重采样；无突变；无选择 |
| 测试 | 交叉不改父本；突变边界；同 seed 种群可复现；种群大小恒定 |
| 可视化 | 代数—均值/最好/方差曲线；基因分布 |
| 验收 | 30 seed 下，选择+突变相对随机重采样有明确提升；报告效应量和失败 seed |
| 停止条件 | 如果固定策略已经把任务做满，换任务；不要把分数上升误读为复杂智能 |

## Stage 03：感知—动作闭环

**作者对应线索**：`history/002_first_eye`、`history/003_trap`、`result2.gif`、`result3.gif`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 让策略只读取 `Observation`，不能读取世界真值 |
| 假设 H03 | 当观察中含局部食物/危险信号时，基于观察的策略能超过无观察策略 |
| 最小环境 | 局部 3×3 视野；食物、陷阱、墙；动作五选一 |
| 模块 | `Observation`、`Sensor`、`Action`、环境隐藏状态、策略接口 |
| 对照 | 随机；仅位置/时间策略；完整世界真值策略（仅作上限） |
| 测试 | 观察窗口裁剪；视野外不可见；策略 API 不暴露 `WorldState` |
| 可视化 | 轨迹叠图、观察窗口和动作日志 |
| 验收 | 观察策略在隐藏布局测试集上胜过随机，同时不访问真值 |
| 奖励投机 | 固定出生点、食物位置或时间规律会泄漏答案；必须随机化且分集合 |

## Stage 04：单一行为任务，不混合认知结论

**作者对应线索**：`003a_legs`、`004_seasaw`、`006_snake`、`007_earthquake`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 分别验证运动、平衡、逃避；不把它们合并成“意识” |
| 假设 H04 | 某一策略/演化编码能在定义任务上优于 baseline |
| 最小任务 | 先选一个：避陷阱、静态平衡、逃离追逐者；一次只做一个 |
| 模块 | 可替换 `TaskEnvironment`、统一 `FitnessBreakdown` |
| 对照 | 随机、手工规则、固定拓扑演化（若已实现） |
| 测试 | 碰撞、奖励、终止、追逐顺序等确定性单测 |
| 可视化 | 只回放指标最接近中位数的 seed，不只展示最好 seed |
| 验收 | 隐藏地图和扰动中仍优于 baseline；报告能耗和失败模式 |
| 停止条件 | 若策略利用起点/刷新顺序，不增加模型复杂度，先修环境 |

## Stage 05：发育式基因型与树分裂

**作者对应线索**：`008_*` 到 `013_tree2`；素材 `result13_frog3d.gif`、`result16_cell_split.gif`、`result17_tree_grow.gif`、`result18_yinyan_eatfood.gif`、`result19_tree4.png`、`depth_tree.png`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 验证“短基因 → 空间结构”的压缩表达，不直接声称脑结构 |
| 假设 H05 | 固定长度的树分裂程序可生成可重复的二维节点/连接布局，并有可控复杂度 |
| 最小任务 | 2D 四叉树或二叉树；基因决定 split/leaf/type；最大深度 4 |
| 模块 | `DevelopmentProgram`、`TreeNodeGene`、`PhenotypeBuilder`、结构验证器 |
| 对照 | 直接随机散点布局；相同节点预算 |
| 测试 | 同基因同 seed 生成同布局；深度/节点上限；无重叠或有明确规则；序列化往返 |
| 可视化 | 静态树图、节点类型颜色、复杂度统计 |
| 验收 | 结构生成完全确定、可序列化、可突变；之后才能接到行为任务 |
| 常见误判 | 生成像“鱼/树”的图案不等于生成了可计算的神经回路 |

## Stage 06：单像素条件反射

**作者对应线索**：`014_3cells`、`016a_OneInput`、`016c_OneInput`、`016c1_OneInput`；素材 `result20_3cells*.gif`、`result22_016c1.gif`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 严格区分先天反射、探索和“看到信号后预测结果” |
| 假设 H06 | 训练中出现视觉 X→甜、视觉 Y→苦后，测试时只给 X/Y，个体能分别咬/松口，且不读取味觉 |
| 最小环境 | 一个二值视觉输入；动作 `BITE/RELEASE/IDLE`；训练期反馈甜/苦；测试期反馈遮蔽 |
| 模块 | `PlasticityRule`、短期痕迹、感知/动作时序、训练/测试 runner |
| 对照 | 不更新权重；随机动作；直接硬编码映射（标为上限） |
| 测试 | 测试期味觉输入恒为零；权重只在训练允许时变化；动作先于反馈；时间线正确 |
| 可视化 | 每 episode 的视觉、动作、反馈、权重轨迹；不要只画连线 |
| 验收 | 30 seed 隐藏测试准确率预先设阈值（建议 ≥80%）且显著高于无学习 baseline；同时空咬率受控 |
| 奖励投机 | 永远咬、永远不动、根据 episode 序号猜答案均应在测试中失败 |

## Stage 07：双像素模式的条件反射

**作者对应线索**：`015_testinput3`、`016b_twoinput_unfinish`、`016d_TwoInput_fail`、`017_TwoInput_fail`；素材 `result21_input3.png`、`result23_016d.gif`。

| 项目 | 内容 |
|---|---|
| 学习目标 | 用最小、清晰的模式组合测试表征与泛化，而不是直接跳到图像识别 |
| 假设 H07 | 双像素 `[0,1]` 与 `[1,0]` 对应不同结果时，具备中间层/发育结构/可塑性的系统能在未见噪声或排列下优于线性/随机 baseline |
| 最小环境 | 两位二值视觉；训练组合与隐藏测试组合预先写入配置；可加入轻微 bit flip 噪声 |
| 模块 | `PatternDataset`、分层/发育网络构建器、`ExperimentRunner`、混淆矩阵 |
| 对照 | 单层阈值网络、随机策略、固定规则、无可塑性版本 |
| 测试 | 数据集划分不可泄漏；XOR/不可线性分离任务的预期；混淆矩阵正确；训练时不读取测试标签 |
| 可视化 | 输入模式热图、混淆矩阵、准确率/空咬率、代表性中位数轨迹 |
| 验收 | 30 seed 下隐藏测试超过所有已定义 baseline；若做不到，输出失败归因而非继续加“脑区”名词 |
| 停止条件 | 若只能记住固定四个模式，不能在噪声/位置变化中保持能力，只能称查表，不称模式泛化 |

## Stage 08：诚实复盘当前 018 原型

**迁移前参考**：018 的 Java 原型曾位于 `core/src/main/java/ai/`；Java 源已按 fork 迁移策略移除。其素材为 `result24_018.jpg`，推导记录在 `record/AI问答*.txt`。当前可执行等价核心位于 `frog/model.py`、`frog/network.py`、`frog/search.py`、`frog/replay.py` 和 `frog/visualizer.py`。

当前 018 的价值是把“像素、痛/甜、行动、中继节点、带化学标签的连接、可视化”集中到一个可展示原型；但它不应直接作为 Stage 07 的验收实现。按当前源码阅读，它会反复随机生成小网络，并对固定情境筛选满足行为断言的网络；这与完整的种群遗传、跨代选择、发育式基因表达不是一回事。

复盘任务：

1. 拆分 UI、网络、场景、评估；
2. 把随机生成次数、成功率、每 seed 的耗时和通过条件记录下来；
3. 用 Stage 07 的 train/validation/test runner 重放；
4. 增加无学习、无化学调制、随机网络等对照；
5. 只报告它实际通过的行为指标。

## 路线终点与边界

完成 Stage 07 代表：你拥有一个可复现的小型具身/条件反射实验平台。它不推出“通用智能”“自我意识”或真实神经科学结论。若后续继续扩展，应先提出新、可失败的假设，再新增阶段。
